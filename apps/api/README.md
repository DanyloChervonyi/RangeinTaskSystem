# API

Backend application placeholder for the future NestJS + PostgreSQL + Prisma setup.

Planned modules:

- `auth` - registration, login, PassportJS strategies, guards.
- `users` - user profile and lookup logic.
- `workspaces` - workspace CRUD and ownership/access checks.
- `boards` - board CRUD inside accessible workspaces.
- `tasks` - task CRUD inside accessible boards.

No backend dependencies are installed yet.
